# House Price ML API (FastAPI + scikit-learn)

Serve trained machine-learning models as a REST API. Built as a hands-on companion to the
"FastAPI for Machine Learning" course outline: FastAPI basics, path/query parameters, Pydantic
validation, error handling, models loaded once at startup, and batch predictions from a CSV upload.

## What's inside

| Course topic | Where it lives |
|---|---|
| First API, GET/POST, JSON | `app/main.py` (`/`, `/health`, `/models`) |
| Path & query parameters | `GET /models/{model_name}`, `?task=price\|category&output=json\|csv` |
| Pydantic request validation | `app/schemas.py` (`HouseFeatures` with bounds) |
| Error handling & custom errors | `app/errors.py` (422 validation, 503 model missing, 400/413/415 bad upload) |
| Regression + classification models | `training/train.py` (GradientBoosting price model, RandomForest premium/standard) |
| Load model once at startup | `lifespan` in `app/main.py` + `app/model_registry.py` |
| CSV upload + batch predictions | `POST /predict/batch` + `app/services.py` |

## Quick start

```bash
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
python -m training.train        # creates models/*.joblib (+ metadata json)
uvicorn app.main:app --reload
```

Open interactive docs: http://127.0.0.1:8000/docs

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| GET | `/` , `/health` | Service info / health |
| GET | `/models`, `/models/{model_name}` | Loaded models, version, metrics, features |
| POST | `/predict/price` | Predict house price (regression) |
| POST | `/predict/category` | Premium vs standard with probability (classification) |
| POST | `/predict/batch` | Upload a CSV, get predictions as JSON or CSV |

### Single prediction

```bash
curl -X POST http://127.0.0.1:8000/predict/price \
  -H "Content-Type: application/json" \
  -d '{"area_sqft":1800,"bedrooms":3,"bathrooms":2,"age_years":12,"distance_to_city_km":8.5,"garage":true}'
# {"predicted_price":351837.36,"model_version":"..."}
```

### Batch predictions

```bash
curl -X POST "http://127.0.0.1:8000/predict/batch?task=price&output=csv" \
  -F "file=@data/sample_houses.csv" -o predictions.csv
```

Required CSV columns: `area_sqft, bedrooms, bathrooms, age_years, distance_to_city_km, garage`
(`garage` accepts 0/1/true/false/yes/no). Bad rows are reported with CSV line numbers.

### Error format

Every error has the same shape:

```json
{"error": "validation_error", "detail": [{"field": "area_sqft", "message": "Input should be greater than 200"}]}
```

## Project layout

```
app/            FastAPI app (main, schemas, services, errors, model registry, config)
training/       Training script (synthetic dataset, reproducible, works offline)
models/         Saved models + metadata (generated by training)
data/           Sample CSV for batch upload
tests/          Pytest suite using FastAPI TestClient
```

## Using your own data or model

1. Replace `make_dataset()` in `training/train.py` with your loader (keep the `FEATURE_COLUMNS` names).
2. Run `python -m training.train`. Models and metadata are picked up automatically at startup.
3. To add a new feature, update `FEATURE_COLUMNS` in `app/config.py` and the `HouseFeatures` schema.

## Notes

- Data is synthetic, so the metrics are only for demonstration.
- Models are loaded once in the FastAPI lifespan hook, not on each request.
- Config via env vars: `MODEL_DIR`, `MAX_UPLOAD_MB`, `MAX_BATCH_ROWS`.
